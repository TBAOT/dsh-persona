# 兼容性

| 本项目版本 | 平台版本 | 状态 |
|---|---|---|
| 0.1.x | 0.2.1-rc.2 / rc.3 / rc.4 / rc.5 | 已在 rc.5 上实测 |
| 0.1.x | 0.2.1-rc.1 | 未实测 |
| 0.1.x | < 0.2.1-rc.2、>= 0.3.0 | 不支持（`engines.dsh` 会拦下安装） |

## 依赖的公开能力

只用这些接缝，不碰平台内部字段：

- 工具注册（`memory` 工具）
- 系统提示词段落（`persona:user`、`persona:memory`）
- 会话事件（用户/助手消息）与回合结束通知
- 模型调用服务（复盘）
- 默认模型选择（复盘模型回退）

## 已知的环境差异

- 平台升级后若这些接缝改名，插件需要跟版；`engines.dsh` 会先拦住不合规的安装。
- 某些平台版本在安装可选官方包后要求重启才能加载新的插件行——重启一次即可。

## 数据格式版本

记忆文件首行是 `<!-- dsh-persona v1 target=... -->`。格式变更时依靠这一行做迁移；
升级前建议备份 `<DSH_HOME>/personas/`。
